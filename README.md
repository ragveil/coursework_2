## Описание
Консольное приложение для поиска вакансий и последующей работы с полученным результатом.
___

## Установка
1. Клонирование репозитория
```
gh repo clone ragveil/coursework_2
```
2. Установка зависимостей
```
poetry install
```
___
### Запуск и функционал
Запуск программы осуществляется из модуля `main.py`, в котором объединена вся логика проекта.

Возможности программы:
* Поиск вакансий с hh.ru по ключевому слову. В качестве ключевого слова может использоваться вид деятельности, город, название работодателя и прочее.
* Сортировка полученного результата по значениям заработной платы.
* Вывод топовых вакансий. Вы самостоятельно указываете количество вакансий для формирования топа.
* Поиск среди вакансий по заработной плате. Для поиска введите значения минимальной и максимальной заработной платы.
* Поиск среди описаний вакансий по ключевому слову. Обратите внимание, данный поиск производится по описанию/зоне ответственности вакансий.
* Сохранение результата в JSON и CSV файлы.
* Удаление вакансии по ID.
* Просмотр сохраненных вакансий.
* Формирования excel-таблицы и сохранение данных в XLSX-файл.

___
### Модуль `main.py`
Объединяет функционал всех модулей проекта.
___
### Модуль `api.py`
Модуль для работы с api HH.ru.
___
### Модуль `vacancy.py`
Модуль для работы с классом вакансий.
___
### Модуль `utils.py`
Модуль со вспомогательными функциями - сортировка, поиск, фильтрация.
___
### Модуль `saver.py`
Модуль для работы с файлами форматов JSON и CSV.
___
### Модуль `xlsx_saver.py`
Модуль для формирования и сохранения таблицы в Excel.
